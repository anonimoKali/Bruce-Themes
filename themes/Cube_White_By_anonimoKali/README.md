Welcome to **Cube White**, a design inspired by structural modularity and geometric precision. This theme organizes your **Bruce Firmware** interface into a distinct, block-based layout that provides a unique "data-pod" visual experience.

By utilizing crisp lines and a grid-aligned structure, **Cube White** transforms your display into a organized command module, making it easier to parse information at a glance while maintaining a clean, high-contrast aesthetic.

### ✨ Highlights
* **Modular Grid Layout:** Visual elements are arranged in a structured, box-like format that feels modern and industrial.
* **Geometric Clarity:** High-contrast white shapes define the UI, ensuring that icons and text are perfectly framed.
* **Balanced Density:** The grid approach allows for excellent visibility of system states without visual clutter.
* **Futuristic Industrial Look:** Perfect for hardware hackers who appreciate a "ruggedized" and well-organized interface.

### 📱 Supported Versions (Included in ZIP):
- **105px:** M5StickC Plus / Plus 2
- **140px:** T-Embed CC1101 / Plus
- **180px:** CYD (Cheap Yellow Display) & T-Deck
- **192px:** T-LoRa-Pager

### 📦 What's Inside?
- Ready-to-use directory structure.
- `Cube_White.json` configuration files for every resolution.
- Optimized monochrome assets for the unique "Cube" layout.

### 🚀 Installation
1. Download `Cube_White_By_anonimoKali.zip` below.
2. Extract the archive to your computer.
3. Move the folders into the `/themes` directory on your SD card.
4. Go to **Settings > Themes** and select **Cube_White**.
