**Border Simply V2** is the definitive evolution of my minimalist series. Based on the successful layout of the original Border Simply, this version introduces refined border geometry, improved spacing, and polished iconography for a truly "premium" feel.

If the original was good, V2 is precise. Every line, gap, and pixel has been re-tuned to offer the cleanest possible user interface for **Bruce Firmware**. It’s the perfect choice for users who demand a professional, distraction-free environment.

### ✨ Highlights
* **Enhanced Geometry:** The framing borders have been re-calibrated for better screen edge alignment.
* **Optimized Spacing:** Improved padding between menu items makes for a more comfortable reading experience.
* **Refined Assets:** Sharper iconography that holds its definition even on smaller 105px displays.
* **The "Clean-Room" Aesthetic:** Maintains the high-end diagnostic look, now faster and more legible than ever.

### 📱 Supported Versions (Included in ZIP):
- **105px:** M5StickC Plus / Plus 2
- **140px:** T-Embed CC1101 / Plus
- **180px:** CYD (Cheap Yellow Display) & T-Deck
- **192px:** T-LoRa-Pager

### 📦 What's Inside?
- Optimized folder structure for instant installation.
- `Border_Simply_V2.json` configuration files for all resolutions.
- Updated, refined monochrome assets.

### 🚀 Installation
1. Download `Border_Simply_V2_By_anonimoKali.zip` below.
2. Extract the archive to your computer.
3. Move the folders into the `/themes` directory on your SD card.
4. Select **Border_Simply_V2** from the Bruce Theme menu.
