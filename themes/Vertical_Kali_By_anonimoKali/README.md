Elevate your device's interface with **Vertical Kali**, an innovative design concept that redefines menu navigation on **Bruce Firmware**. 

This theme introduces a captivating **layered overlay layout**. While your main menu options scroll vertically in the center, they pass beneath a bold, permanent horizontal banner that highlights the currently selected module (like WiFi) with a sharp, angular accent bar.

---

### 🎨 Design & Visual Highlights:

* **Layered Horizontal Banner:** A central tactical badge featuring clean text and signal iconography, creating an immersive depth-of-field scrolling effect.
* **Iconic Left-Docked Badge:** The legendary Kali Linux dragon logo is locked inside a high-contrast circular frame on the left, keeping the UI perfectly balanced.
* **Futuristic Green Typography:** Menu items utilize a tactical green hue optimized for rapid readability and an authentic terminal vibe during field operations.

### 📦 What's Inside the ZIP?
- Pre-configured folders ready for instant drag-and-drop setup.
- Precision `.json` configuration files mapped for each display architecture.
- Full custom asset packs including the unique overlay graphic components.

### 🚀 Quick Installation
1. Download the `Vertical_Kali_By_anonimoKali.zip` asset package below.
2. Extract the folder on your computer.
3. Transfer the extracted directories into the `/themes` folder of your device's SD card.
4. Open the Bruce menu, navigate to **Settings > Themes**, and execute **Vertical Kali**!
