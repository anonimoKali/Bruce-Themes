### 📱 Supported Versions (Included in ZIP):
- **105px:** M5StickC Plus / Plus 2
- **140px:** T-Embed CC1101 / Plus
- **180px:** CYD (Cheap Yellow Display) & T-Deck
- **192px:** T-LoRa-Pager

### 📦 What's Inside the ZIP?
- Organized standalone directories for all 3 color variations (**Classic**, **White**, **Black**).
- Individual `.json` maps built specifically for each supported hardware resolution.
- Complete asset packs containing the dolphin graphics and customized list layouts.

### 🚀 Quick Installation
1. Download the `Flipper_Bruce_Pack_By_anonimoKali.zip` asset below.
2. Unzip the package on your computer.
3. Choose your preferred variation (or install all three!) and drag the folders into the `/themes` directory of your device's SD card.
4. Access the Bruce options panel, navigate to **Settings > Themes**, and awaken the dolphin!
